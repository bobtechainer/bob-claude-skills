# Creative Axes — divergence menu (anti-template gate)

Purpose: stop every build from converging on the last successful pattern.
The RIGOR is invariant (physics honesty, QC gates, review hooks, legibility).
The CREATIVE SURFACE must vary. At brainstorm, generate 3 concepts that pull
DIFFERENT combinations from these axes; each concept must differ from every
row in `build-registry.md` on ≥2 axes. Never reuse the previous build's full combo.

## Axis 1 — Interaction paradigm (the verb the student lives in)
- drag-experiment (manipulate apparatus directly)        ← faraday
- scroll-film (scrubbed cinematic story)                 ← the-toy
- free-roam explore (WASD/orbit world with discoveries)
- build-assemble (construct the apparatus/creature/circuit yourself, then run it)
- aim-launch (projectile/trajectory games; predict where it lands)
- time-scrub (drag time itself: eras, orbits, decay, seasons)
- conduct-orchestrate (multiple agents/valves/switches, keep a system alive)
- observe-instrument (you control instruments, not the phenomenon: telescope, seismograph)

## Axis 2 — Framing metaphor (where are we?)
lab bench · field expedition · space station window · microscope dive ·
god-view planet in hands · inside-the-machine (you are shrunk) ·
detective case file (phenomenon = mystery to solve) · workshop/garage ·
theater stage with curtains · museum diorama that comes alive

## Axis 3 — Art direction (pick ONE, commit hard)
bright studio (faraday) · night lab neon (double-pendulum) · blueprint/technical ink ·
paper-craft collage · watercolor atlas · retro-futurist NASA poster ·
volcanic dusk / deep-sea dark · brutalist mono + one accent · vaporwave grid

## Axis 4 — Pedagogy shell
guided do-to-advance steps (faraday) · mystery-first (show weird phenomenon,
student investigates before any theory) · sandbox + quest chips ·
story campaign (character needs the physics to survive) ·
prediction duel (student vs sim: bet, run, score) · field notebook
(student collects observations into a journal that becomes the theory)

## Axis 5 — Signature wow-mechanic (exactly ONE per page, must be new)
Examples already spent: ghost ensemble chaos (double-pendulum), living field
lines + Lenz braking + 3D hand (faraday), photo-card synthesis (the-toy).
New candidates: sound-as-data (hear the frequency you tuned), split-screen
counterfactual (what-if runs beside reality), physical scale zoom (atom→planet
continuous), destroy-to-learn (break it and see why), draw-your-own (student
sketches a curve/track and the sim runs on it), swarm particles forming
diagrams, day/night or season morphing the whole scene.

## Rule of use
1. Read `build-registry.md`.
2. Roll/choose 3 concepts, each ≥2 axes different from ALL previous rows,
   and different from each other on ≥2 axes.
3. Present all 3 to the user at brainstorm with one-line "feel" pitches.
4. After design approval, append the chosen combo to `build-registry.md`.
5. If the user explicitly asks for "same style as X", registry rule is waived —
   note the waiver in the registry row.
